# Neon Requiem — Approved Visual Direction

**Status:** Owner approved  
**Recorded:** 2026-11-21  
**Scope:** GitHub project branding and a visual reference for future Foundry interface work  
**Decision context:** The owner approved the revised README design in [PR #5](https://github.com/EmberWolf-Games/neon-requiem-dnd/pull/5), revision `65caa3aa06f8148dc709b56bd6fe9e3ea6e11bde`.

## Direction

Use a gunmetal tactical interface with charcoal surfaces, neon magenta and cyan highlights, futuristic typography, illuminated borders, and the official Neon Requiem artwork. The approved [repository README](../../../README.md) and [branding assets](../../assets/branding/) provide the current GitHub reference.

This direction establishes the project's GitHub branding and a visual reference for future Foundry interface work. It does not authorize interface implementation or changes to the inherited rules engine. Future implementation remains subject to the owner's development assignments and applicable approved design requirements.

## Application and status

- Keep technical information and navigation accessible and readable alongside decorative graphics.
- Preserve artwork provenance, licenses, and third-party attribution; consult [third-party notices](../../../THIRD-PARTY-NOTICES.md) before introducing assets.
- Treat the Character Identity Creator and animated tokens as approved design requirements, not completed features. See the [GDD addendum](../gdd/Neon_Requiem_GDD_Character_Creator_Animation_Addendum_v2.md).
- The Foundry v14 runtime smoke test remains pending; follow the [smoke-test guide](../../SMOKE-TESTING.md) when an authorized remote installation is available.
- This decision has not been incorporated into a confirmed canonical GDD; its location and version remain unconfirmed.
