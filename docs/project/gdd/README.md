## Pre-approved subclass feature designs (owner says future tuning permitted)

**18 subclasses × 10 milestones = 180 subclass features**. All subclasses progress at class levels **3, 7, 11, 15, 19, 23, 27, 31, 35 and 39**. The six approved base classes retain their existing ASI/feat slots and the Ripperdoc hybrid has no subclass track.
